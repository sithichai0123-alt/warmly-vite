# Firestore Rules ของ Warmly (ฉบับร่าง)

`firestore.rules.draft` — กฎที่ร่างไว้แทน `allow read, write: if true` **ยังไม่ถูกใช้งานจริง**
ต้องไปวางใน Firebase Console → Firestore Database → Rules เอง (ไฟล์นี้ไม่ได้ deploy อัตโนมัติ)

## ก่อนวางกฎจริง (สำคัญ)
1. เปิด **Anonymous** ใน Authentication → Sign-in method แล้ว deploy โค้ดที่ผู้เยี่ยมชมล็อกอินนิรนาม (PR ขั้น 1) แล้ว
2. ดูแท็บ Authentication → Users ว่ามีบัญชีแบบ Anonymous โผล่ตอนมีคนเข้าแบบผู้เยี่ยมชม
3. คัดลอกกฎเก่าเก็บไว้ (ย้อนกลับได้ทันทีโดยวางกลับ)
4. วางกฎใหม่ → Publish → รีโหลดแอปทุกแท็บ → ไล่เช็กตามรายการด้านล่าง

```bash
cd firebase/rules-test && npm install && npm test
```

## ข้อจำกัดที่รู้อยู่
- โบนัสรายวัน (+20/+70) คำนวณฝั่งเครื่องผู้ใช้ กฎจำกัดเพดานได้แต่กันการไล่รับซ้ำไม่ได้ → ควรย้ายไปเซิร์ฟเวอร์ (`api/`)
- การลบข้อความเก่าห้องรวม/ห้องเสียง ทำจากเครื่องผู้ใช้ จึงยังให้ทุกคนที่ล็อกอินลบได้ → ควรย้ายไปเซิร์ฟเวอร์
- ห้องเสียง (สมาชิก/เตะ/เพลย์ลิสต์) และกล่องปลุกสายยังเขียนได้โดยทุกคนที่ล็อกอิน
- ความคิดเห็นในโพสต์เก็บเป็นอาร์เรย์ กฎตรวจเนื้อหาในอาร์เรย์ไม่ได้ ผู้ล็อกอินจึงเขียนทับความเห็นคนอื่นได้ถ้าจงใจ
- โพสต์ที่ตั้งเป็นส่วนตัว/เพื่อนเท่านั้น ถูกซ่อนที่ฝั่งแอป ผู้ล็อกอินที่เขียนสคริปต์ยังอ่านได้
- ผู้เยี่ยมชมสร้างบัญชีนิรนามได้ฟรี → "ต้องล็อกอิน" กันคนนอกได้ แต่ไม่ได้กันคนที่ตั้งใจสมัครบัญชีนิรนามมาอ่านฟีด/รายชื่อ
  (ข้อมูลส่วนตัวจริง — แชทส่วนตัว ประวัติเหรียญ รายชื่อที่บล็อก คำเชิญ สายโทร — ผูกกับตัวตนและกันไว้แล้ว)
